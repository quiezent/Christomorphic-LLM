# Codex audit evidence

`claims.json` lists the 196 load-bearing claims in Codex's public documents that the seven auditor passes traced to primary records. Each entry gives the unit, where the claim appears and the claim. [CODEX_AUDIT.md](../../CODEX_AUDIT.md) sets these statements beside what the primary records show. Those records sit in Clayton's local archive, which holds licensed Scripture and private session records, so they are not republished here.
